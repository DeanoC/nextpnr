# Mixed-width M10K hardware diagnostics, 2026-09-08

All eleven retained RBFs passed the three probe sections on the designated
DE10-Nano kit under owner `nextpnr-m10k-mixed-width`, using kit.py leases and
its normal load/stop/development reboot recovery protocol. This is acceptance
of these exact diagnostic artifacts, not a production MiSTer image.

These are the exact compressed OSS RBFs generated by `../../mixed_width.py`.
`results.json` records SHA256 values of the RBFs after removing the outer gzip
wrapper, tool binary hashes, source hashes, base revisions and host reports.
The FPGA payload itself uses nextpnr's `--compress-rbf` encoding.

All cases use one M10K, one PLL and one HPS GP interface. They use the
DE10-Nano's 50 MHz reference for writes and a gated 25 MHz PLL clock for
reads. They do not exercise a non-50 MHz reference. Reported Fmax describes
the write-clock paths; settled-data probing does not establish CDC timing
acceptance. The source files and probe live two directories above this one.

The tools were built from nextpnr `71d2ffdbdf669475d6596352990f4d22d90a9092`
plus this change, and Yosys `a18445dc033592cd568f2ac71317d94048042551`.
Mistral remains `78ba2a580ae2523403d4f4f91891a6b11d7b6aba`. Board QSF/SDC
come from misteross `ffdac202fd52e06855afb7d2baa8d4946ff765db`.

For example, extract 40→10 with:

```sh
gzip -dc u10-w4-r1.rbf.gz > /tmp/mixed-40-to-10.rbf
sha256sum /tmp/mixed-40-to-10.rbf
python3 ../../mixed_width_probe.py --unit 10 --write-lanes 4 --read-lanes 1 > /tmp/probe.sh
```

Verify the hash against `results.json`, load under an authorized `kit.py`
session, and execute the probe on the target. The probe checks initialized
words, low-address-first slice order, narrow writes preserving neighbors,
writes while the read clock is stopped, and read-enable hold. It stages GP
address/data and write enable separately to avoid asynchronous bus skew
causing incidental writes. Return through kit.py stop/reboot recovery and
release; do not bypass another owner's lease.

Host runs explicitly selected router1. Router2 stalled on the 40→10 fixture,
so successful router1 artifacts do not establish default-router support.
