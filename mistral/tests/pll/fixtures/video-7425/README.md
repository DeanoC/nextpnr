# 50 MHz → 74.25 MHz PLL oracle

This portable Quartus Prime Lite 17.0.2 source project targets `5CSEBA6U23I7`,
V11 reference, one zero-phase 50%-duty output and direct fractional-N mode.
Run `quartus_sh -t /path/to/oracle.tcl` from an empty build directory, then
`quartus_sh --flow compile top`. Sources are resolved relative to the Tcl file.

The checked feedback configuration is M8/N1 (bypass), C6=6, fractional word
K=`0xe8f5c239`, BW7/CP2 and M presets1/0. Both C counts are3. The calculated
output is 74,249,999.83243954 Hz (−0.00225670644 ppm). This retains Quartus's
word rather than deriving a new analog configuration or rounding policy.

`quartus.rbf.gz` retains the exact oracle artifact; `oracle.json` contains
its uncompressed SHA256 and all non-default selected-FPLL settings. Extract
with `gzip -dc quartus.rbf.gz > /tmp/quartus-7425.rbf`. Use `mistral-cv decomp
5CSEBA6U23I7 /tmp/quartus-7425.rbf /tmp/quartus-7425.bt` to inspect it.

The OSS diagnostic is generated by `../../fractional.py --mhz 74.25` with
the usual tool arguments. Add `--oracle-bt /tmp/quartus-7425.bt` to compare
the entire selected-FPLL configuration. The source uses the existing
meter/reset protocol and signature `0xD742`; its target probe is
`../../fractional_probe.sh 74.25`, run only under an exclusive kit session.

## Exact-artifact kit result

`oss.rbf.gz` passed ten reset/relock and frequency measurements on the
designated kit on 2026-09-08. Every held-reset window counted zero; running
windows counted 6082 or 6083 (nominal 6082.56). The kit.py stop/reboot/release
cycle returned free. `hardware.json` records source/binary identities,
uncompressed RBF SHA256, utilization, timing and all measurements;
`probe-results.txt` retains sanitized probe output.

The image uses one PLL, two clock buffers and one HPS GP interface, with no
DSP, M10K or MLAB. Reported Fmax is 343.879 MHz against the generated 74.25 MHz
constraint and 195.274 MHz against the 50 MHz reference. The meter checks
ratio and reset behavior, not sub-ppm metrology, jitter or HDMI acceptance.
